The account hero — one per account, gradient keyed to account meaning (grape = spending, mint = savings, tangerine = goal, berry = debt).

```jsx
<BalanceCard kind="savings" cents={12480} size="hero" note="+$0.42 interest in May" noteIcon="sparkles" />
```

Use `size="hero"` for the single focal balance at the top of kid mode; `md` for the secondary account beside it.
