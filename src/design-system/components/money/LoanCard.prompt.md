Parent-to-child loan summary — principal, what's still owed, payoff progress, next payment.

```jsx
<LoanCard title="Skateboard loan" principalCents={4000} remainingCents={2600} ratePct={4} nextPayment={500} nextDue="Fri" />
```

Progress fill is mint (what's been paid), the figure is berry (what's owed) — debt is always berry in this system, never grape.
