The main action control — chunky pill with a solid drop shadow that collapses on press.

```jsx
<Button variant="primary" size="lg" icon="plus" fullWidth>Add money</Button>
<Button variant="secondary" size="md">Cancel</Button>
```

Variants: `primary` (grape — the default action), `accent` (tangerine — celebratory / hero CTA, max one per screen), `secondary` (outlined, for cancel/secondary), `ghost` (inline text action), `danger`. Sizes: `lg` for kid-mode primary actions and marketing CTAs, `md` default, `sm` for dense parent tables. In parent mode the radius token makes these squarer automatically.
